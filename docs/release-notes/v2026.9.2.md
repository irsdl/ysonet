## Highlights

Compared with v2026.9.1, this release improves discovery, scripting, and release
verification:

- Compact help and clearer wizard settings make options easier to find.
- `doctor` checks an installation without running payloads. The
  [JSON catalog](https://irsdl.github.io/ysonet/json-catalog/) provides
  structured metadata and a versioned schema for integrations.
- The [documentation website](https://irsdl.github.io/ysonet/) adds searchable
  guides and module references, with light and dark themes. Pages are generated
  from the repository docs and public CLI metadata.
- Release downloads include checksums, signed build provenance, component
  inventory, and runtime observations. See
  [release verification](https://irsdl.github.io/ysonet/release-verification/).

## Compatibility and upgrade

Extract the entire ZIP into a fresh folder. Windows and .NET Framework 4.7.2 or
newer 4.x remain required; native Linux/macOS execution is not established.

Scripts must check the exit code: invalid or incomplete one-shot commands and
failed writes now exit nonzero. Diagnostics go to stderr; requested data goes to
stdout or `--outputpath`. Successful formatter searches exit zero. Help is now
compact; use `--fullhelp` for the exhaustive reference or `--list catalog` for
structured discovery. Existing name/value listings retain their line-based format.

## Known limitations

Catalog declarations are not execution results or guarantees about a target.
Runtime reports distinguish observed outcomes from unverified cells. A green test
tier does not establish every module, formatter, runtime, or target combination.
The website follows current source and may describe changes newer than a download.

commit. The attached `test-results.md` records their actual totals, environment

and ZIP. The separate OOB, DoS, LEGACY, and NET40 tiers are not publication gates
and were not run by the CI above.
